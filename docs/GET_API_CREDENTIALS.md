# Current credential setup

The escaped historical guide below is retained for reference, not current
deployment instructions. Use `.env.example` for variable names and
[the provider operations checklist](platform-guide.md#provider-operations-checklist)
for authorized rotation and sender verification.

- GitHub: prefer a fine-grained token restricted to this repository with Issues
  read/write. Classic tokens have no separate `issues` scope.
- Resend: configure `RESEND_API_KEY` and a verified `INVITE_FROM_EMAIL`;
  configure `COMPLIANCE_FROM_EMAIL` for compliance reminders.
- SendGrid: restrict the API key to Mail Send and verify the exact sender domain
  or address in `SENDGRID_FROM_EMAIL`.
- Store actual credentials only in provider secrets or private untracked local
  configuration. Never paste them into commands recorded in shared logs.
- Confirm acceptance and delivery independently using provider event logs.
