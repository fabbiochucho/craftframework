# Regulatory source re-verification procedure

Run before each reporting cycle and at least every 12 months. Prepared 15 October 2026.

## Where

**Workspace → Regulatory sources.** It lists 108 sources: the IFRS S1/S2 adoption basis for each of the 54 African countries (8 detailed rule packs, 46 generated from the country registry) and a capital-market and institutional profile for each country. Each shows its status: verified, re-verification due, changed, or not yet verified.

## Priority sources (detailed rule packs)

| Body | Country | What to confirm |
|---|---|---|
| SEC Nigeria; FRCN | Nigeria | Circular dates and scope; SRG 1 categories, effective dates and readiness test |
| ICPAK | Kenya | Phase dates by entity category; readiness-assessment deadline |
| ICAG | Ghana | Roadmap categories and dates; public-sector position |
| ZICA | Zambia | Scope for publicly accountable entities; reliefs |
| NBAA | Tanzania | Technical Pronouncement dates and scope; scope 3 relief |
| PAAB | Zimbabwe | Category dates, reliefs and full-compliance dates |
| ICPAR | Rwanda | Phase dates, climate-only and full ISSB phases |
| JSE / FSCA | South Africa | **Verify the South Africa position:** whether any mandatory ISSB adoption has been announced since the voluntary JSE guidance |
| IFRS Foundation | Uganda | Status of the published snapshot; whether a final framework has been adopted |

Also check the IFRS Foundation "use by jurisdiction" page for any new African jurisdiction, and the country profiles flagged with fields to verify (regulator, exchange, sustainability-disclosure rules, accountancy body, NPHI).

## Steps

1. Open each source link; if it has moved, find the authority’s current page.
2. Compare dates, entity categories, scope and reliefs with what CRAFT shows.
3. Record the check on the Regulatory sources page:
   - **Confirmed unchanged** (an optional note);
   - **Changed** — note exactly what changed and where; the platform team updates the rule pack, which creates a new checklist version;
   - **Source unreachable** — note what was tried.
4. A source shows as verified for 365 days after the last confirmation.
5. Before finalising an ESG report QA period, make sure its jurisdiction’s sources are verified.

## Escalation

Changes to a rule pack (dates, categories, scope) are made by the platform team, tested, and released as a new checklist version (currently CRAFT-QA 1.3). Existing finalised periods keep their frozen version.
